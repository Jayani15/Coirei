# Autonomous Complaint Decision AI Agent

## Project Overview

This project is an AI-powered complaint analysis system that automatically processes customer complaints and makes intelligent business decisions using LLMs.

The system accepts complaint text as input, classifies the complaint type, detects sentiment and urgency, decides the best action to take, generates reasoning for that decision, and assigns a priority score.

This helps businesses automate complaint handling and improve customer support efficiency.

---

## Features

* Complaint Category Classification
  (Delivery / Payment / Service / Technical)

* Sentiment Detection
  (Positive / Neutral / Negative)

* Urgency Level Detection
  (Low / Medium / High)

* Intelligent Decision Engine
  (Refund / Escalate / Resolve)

* Justification Generation

* Priority Score Assignment
  (1 to 10)

* Structured JSON Output

* Human-readable Decision Report

## Installation

### Step 1: Clone the Project

```bash
git clone <your-repo-link>
cd autonomous-complaint-ai-agent
```

---

### Step 2: Create Virtual Environment

```bash
python -m venv venv
```

Activate it:

### Windows

```bash
venv\Scripts\activate
```

### Mac/Linux

```bash
source venv/bin/activate
```

---

### Step 3: Install Dependencies

```bash
pip install -r requirements.txt
```

---

## Environment Variables

Create a `.env` file in the root folder:

```env
GROQ_API_KEY=your_groq_api_key_here
```

Get your API key from Groq Cloud.

---

## Run the Project

```bash
python main.py
```

---

## Output Files

### `output/result.json`

Stores the structured JSON response generated by the AI agent.

### `output/report.txt`

Stores the human-readable complaint decision report with reasoning.
